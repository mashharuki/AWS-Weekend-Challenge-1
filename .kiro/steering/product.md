# プロダクト概要

AWS Community Builder が日々の発信につなげられる記事・アプリのアイデアを、継続的に収集・評価・整形して届ける、常時稼働のクリエイティブエージェントを構築する。利用者が手動で実行しなくても、新しい英語の Markdown コンテンツを定期的に生成し、後から閲覧できる状態にすることを目的とする。

## 中核となる機能

- 定期トリガーによる、手動操作に依存しない情報収集とコンテンツ生成
- エージェントワークフローによる関連性・トレンド・内容の評価と整形
- 英語のブログ形式 Markdown としての創作的な出力の保存
- Web UI による生成済みコンテンツの閲覧
- AWS 上への一括デプロイと、動作の再現可能性

## 主なユースケース

- Community Builder が毎日の執筆・アプリ企画の着想を得る
- 生成結果を確認し、記事やアプリのたたき台として再利用する
- スケジュール実行による自律的な出力生成をデモ・証跡として提示する

## 提供価値

単なる情報一覧ではなく、毎日自動で実行されるエージェントが、収集結果を発信可能な Markdown の形へまとめる。AWS のマネージドサービスを組み合わせることで、利用者の常時操作なしに継続するクリエイティブな体験を提供する。
